# Data

This folder is for small sample datasets and test recordings.

Do not commit large raw datasets to Git.

Example future CSV format:

```text
timestamp_ms,ax,ay,az,gx,gy,gz
0,0.01,0.02,1.00,0.2,-0.1,0.0
10,0.02,0.03,1.01,0.3,-0.1,0.1
```

The data is intended for visualization, debugging, and threshold tuning only.
