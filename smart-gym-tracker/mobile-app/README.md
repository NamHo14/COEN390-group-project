# Mobile App

The mobile app will connect to the ESP32 over BLE.

## Planned Screens

- Home
- Connect Device
- Exercise Selection
- Workout
- Workout History
- Settings

## Workout Screen

Planned values:

- Exercise name
- Current set
- Rep count
- Last rep duration
- Average rep tempo
- Rest timer
- Battery level
- Start / Stop workout
- Reset set

The app framework is intentionally left open for now.
