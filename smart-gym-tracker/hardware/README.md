# Hardware

Hardware design files will live here.

## Planned Subfolders

- `pcb/` — custom PCB design
- `schematics/` — circuit schematics
- `enclosure/` — CAD/enclosure files
- `bom/` — bill of materials

## First Prototype

The first prototype can use:

- ESP32-WROOM-32 development board
- MPU9250 IMU
- USB power

A rechargeable battery and custom PCB can be added later.
