# Mobile App Scaffold

This is a framework-agnostic starter structure for the Smart Gym Tracker mobile app.

## Required product rule
- User manually selects exercise before workout start.
- No ML and no automatic exercise recognition.

## Planned screens
- Home
- Connect Device
- Exercise Selection
- Workout
- Workout History
- Settings

## Notes
- BLE integration is intentionally TODO.
- Persistence/workout history storage is intentionally TODO.
- Framework selection (Flutter/React Native/native) is intentionally deferred.
