# Hardware

This folder tracks hardware design assets for Smart Gym Tracker.

## Subfolders
- `pcb/`: PCB design files and production exports.
- `schematics/`: Electrical schematics.
- `enclosure/`: Mechanical enclosure models and drafts.
- `bom/`: Bill of materials and sourcing notes.

## Hardware intent
- ESP32-based design with IMU and BLE.
- Battery charging + regulation support.
- Optional haptic feedback motor.

## Status
Hardware files are placeholders in this foundation phase.
